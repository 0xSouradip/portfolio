Clean Energy Innovation · Lead System Architect
Source Code

Har Kadam Bijli Ka (हर कदम बिजली का)

A Hybrid Kinetic Piezoelectric and Bifacial Solar Energy Harvesting System for High-Density Railway Stations.

Engineered as Lead System Architect, this project introduces a climate-resilient microgrid infrastructure for public transit. It captures kinetic mechanical energy from passenger foot traffic across footbridges and turnstiles (4.5–6.8 Joules per step) alongside rooftop N-Type TOPCon bifacial solar canopies to power station signaling, passenger displays, and emergency lighting.

⚡
Kinetic Harvesting & Physics Model: Formulated mathematical piezo generation & dual-stage pinion gear mechanical energy yield models.
🌐
Interactive Simulator & Canvas Engine: Developed real-time HTML5 Canvas particle flow simulation, Web Audio API piezo acoustic synthesizer, and station load calculators.
📊
Microgrid Telemetry: Diurnal load curves with Chart.js, ESG carbon offset counters, and parameter sliders (footfall, tile density, canopy area).
Piezoelectric Modeling Renewable Energy Systems HTML5 Canvas Engine Web Audio API Chart.js Vanilla JavaScript
